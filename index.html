A FRAMEWORK FOR AWS LAMBDAS · PYTHON / NODE / TYPESCRIPT

The happy path,
in every language.

Acai is a DRY, declarative framework for AWS Lambdas. One philosophy, three runtimes — validate every input first, then write only the code that matters.

“No nested try/catch. No mid-level exceptions. Just the path your code was meant to take.”

Happy Path Programming is a simple idea: all inputs are validated before they are operated on. Acai's layers of configurable middleware let you declare what a valid input looks like — required bodies, headers, OpenAPI schemas — so invalid requests never reach your business logic.

What's left is code that reads the way you meant it: no defensive conditionals, no exception plumbing, no boilerplate. Just the happy path.

NODEacai-js
THE HANDLER — validated before it runs
// handlers/sqs.js
const { sqs } = require('acai');

exports.handle = async (event) => {
    const sqsEvent = new sqs.Event(event, {
        requiredBody: 'v1-sqs-event',
        schemaPath: 'openapi.yml'
    });
    const records = await sqsEvent.getRecords();
    for (const record of records) {
        await process(record.body);
    }
};

import { Event } from 'acai-ts/sqs';
import { SQSEvent } from 'aws-lambda';
